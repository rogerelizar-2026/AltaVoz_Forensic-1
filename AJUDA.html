Guia de Instalação - Solução de Problemas

❌ Problema Encontrado

Erro: "Arquivo package.json não encontrado!"

Isso significa que o instalador está sendo executado na pasta errada.

✅ Solução em 3 Passos

1

Localizar a pasta do projeto

Abra o Windows Explorer e procure a pasta onde você baixou o projeto. Ela deve ter estes arquivos:

📁 altavoz-forensic-1/
   📄 package.json         ← ESTE ARQUIVO DEVE EXISTIR
   📄 install.bat
   📄 download-models.bat
   📁 src/
   📁 public/
2

Abrir o terminal na pasta correta

Opção A - Windows 11:

  • Abra a pasta do projeto no Windows Explorer
  • Clique na barra de endereço (onde mostra o caminho)
  • Digite cmd e pressione Enter

Opção B - Windows 10:

  • Abra a pasta do projeto no Windows Explorer
  • Clique com o botão direito em um espaço vazio
  • Selecione "Abrir janela de comando aqui" ou "Abrir no Terminal"

Opção C - Manual:

  • Abra o Prompt de Comando (cmd)
  • Navegue até a pasta usando o comando cd:
cd C:\Users\SeuNome\Downloads\altavoz-forensic-1

(substitua pelo caminho real da sua pasta)

3

Executar o instalador

No terminal que abriu na pasta correta, digite:

INSTALAR.bat

e pressione Enter.

⚠️ Importante

Não execute o instalador de qualquer lugar!

Você precisa estar dentro da pasta do projeto para que o instalador funcione corretamente.

🎉 Pronto!

Após seguir os 3 passos, o instalador vai:

  • ✓ Verificar o Node.js
  • ✓ Instalar as dependências
  • ✓ Preparar o sistema

Depois execute na ordem:

download-models.bat → start.bat
