Solução: Node.js Instalado mas Não Encontrado

❌ Problema

Você instalou o Node.js 24, mas o instalador diz:

❌ Node.js NÃO ENCONTRADO!

Causa: O Windows não consegue encontrar o Node.js porque o PATH não foi configurado durante a instalação.

Escolha a Solução:

🚀 Solução 1

Instalador Universal
(Mais Fácil)

🔧 Solução 2

Instalador Manual
(Mais Controle)

🔄 Solução 3

Reinstalar Node.js
(Mais Confiável)

🚀 Solução 1: Instalador Universal

Esta é a solução mais fácil. O instalador procura o Node.js em todos os locais possíveis.

1

Executar o Instalador Universal

Dê duplo clique no arquivo:

📄 INSTALAR-UNIVERSAL.bat
2

Aguarde a Detecção

O instalador vai automaticamente:

  • ✓ Procurar o Node.js em todos os locais comuns
  • ✓ Detectar a versão instalada
  • ✓ Configurar o PATH automaticamente
3

Se Não Encontrar Automaticamente

O instalador vai pedir o caminho do Node.js. Digite o caminho onde você encontrou o node.exe.

Dica: Use a busca do Windows (Win + S) e digite "node.exe" para encontrar.

✅ Pronto!

O instalador vai configurar tudo automaticamente e continuar com a instalação do AltaVoz.

🔧 Solução 2: Instalador Manual

Use esta solução se você sabe onde o Node.js está instalado e quer mais controle.

1

Encontrar o Node.exe

Abra o Windows Explorer e procure por node.exe em:

C:\Program Files\nodejs\node.exe
C:\Program Files (x86)\nodejs\node.exe
C:\Users\SEU_USUARIO\AppData\Local\Programs\nodejs\node.exe
C:\Users\SEU_USUARIO\AppData\Roaming\npm\node.exe

Dica: Pressione Win + S e digite "node.exe" para buscar.

2

Copiar o Caminho

Quando encontrar o node.exe, copie o caminho da pasta (não do arquivo).

Exemplo: C:\Program Files\nodejs

3

Executar o Instalador Manual

Dê duplo clique no arquivo:

📄 INSTALAR-MANUAL.bat
4

Digitar o Caminho

Quando o instalador pedir, cole o caminho da pasta do Node.js que você copiou.

⚠️ Importante

Esta solução configura o Node.js apenas para a sessão atual. Para usar permanentemente, você precisa adicionar ao PATH do Windows (veja Solução 3).

🔄 Solução 3: Reinstalar o Node.js

Esta é a solução mais confiável. Reinstala o Node.js com o PATH configurado corretamente.

1

Desinstalar o Node.js Atual

1. Pressione Win + I (Configurações)

2. Vá em Aplicativos → Aplicativos instalados

3. Procure Node.js

4. Clique em Desinstalar

2

Baixar o Node.js

1. Acesse: https://nodejs.org/pt-br/download

2. Clique no botão verde "LTS" (versão recomendada)

3. Aguarde o download

3

Instalar Corretamente

Execute o instalador baixado e siga estas etapas:

  • ✓ Clique em Next
  • ✓ Aceite os termos (checkbox)
  • ✓ Clique em Next
  • ✓ Mantenha o caminho padrão
  • ✓ MUITO IMPORTANTE: Marque "Add to PATH"
  • ✓ Clique em Next
  • ✓ Clique em Install
  • ✓ Clique em Finish
4

Reiniciar o Computador

Reinicie o computador para garantir que o PATH seja atualizado.

5

Testar a Instalação

Abra um novo Prompt de Comando e execute:

node --version

Deve aparecer: v24.x.x

6

Executar o Instalador do AltaVoz

Agora execute normalmente:

📄 INSTALAR.bat

✅ Pronto!

O Node.js está instalado corretamente e o PATH está configurado. O instalador do AltaVoz vai funcionar sem problemas.
